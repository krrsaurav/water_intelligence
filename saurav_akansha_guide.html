Water Intelligence

Beginner Roadmap & Execution Guide for Saurav (Frontend) & Akansha (Database)

1 What is the Project in Simple Words?

Water Intelligence is an AI-powered early warning decision platform for water scarcity.
Standard monitoring systems only show today’s reservoir numbers and warn people after shortages occur. Our platform combines rainfall deficits + surging demand + depleting groundwater to predict water stress 4 to 7 days ahead, giving municipal authorities time to act.

3 How Saurav & Akansha Connect (The 3-Step Handshake)

Step 1 Akansha creates SQLite tables storing rainfall, storage levels, and consumption.
Step 2 Deep & Bhavishya pull records from Akansha's DB, run Machine Learning, and produce prediction JSON.
Step 3 Saurav receives the JSON and renders the 4-day forecast bar chart, map pins, and risk alerts!

4 Akansha's SQLite Database Schema (Starter Template)

-- Table 1: Regional Telemetry (Districts) CREATE TABLE regions ( region_id TEXT PRIMARY KEY, -- 'delhi', 'jaipur', 'bundelkhand' region_name TEXT NOT NULL, -- 'Delhi NCR' state TEXT, -- 'Delhi' storage_capacity_pct REAL, -- 34.0 (%) groundwater_depth_m REAL, -- 38.5 (meters) risk_status TEXT -- 'LOW', 'MODERATE', 'HIGH', 'CRITICAL' ); -- Table 2: 4-Day AI Forecast Results (What Saurav renders in Chart.js) CREATE TABLE forecast_4days ( id INTEGER PRIMARY KEY AUTOINCREMENT, region_id TEXT, day_name TEXT, -- 'Today', 'Day 2', 'Day 3', 'Day 4' predicted_availability REAL, -- 58.0, 48.0, 38.0, 28.0 badge_label TEXT -- 'Moderate', 'Stressed', 'High Risk', 'Critical' );

5 7-Day Beginner Study Roadmap (Step-by-Step)

Timeline Saurav (Frontend & UI) Akansha (Database & SQL)
Days 1 – 2 HTML & CSS: Learn <select>, <div>, <canvas> and basic Tailwind classes for badges & cards. SQL Basics: Learn CREATE TABLE, INSERT INTO, SELECT * FROM, and WHERE filtering.
Days 3 – 4 JavaScript DOM: Learn document.getElementById() to update text, colors, and badges on user click. SQLite & DB Browser: Install DB Browser for SQLite and practice creating district tables with sample test data.
Days 5 – 6 Chart.js & Leaflet: Learn how Chart.js turns an array [58, 48, 38, 28] into colored bars and Leaflet into map pins. Python + SQLite: Write a 5-line Python script using import sqlite3 to query database rows into JSON dictionaries.
Day 7 Demo Polishing: Test region switching and practice clicking the "Simulate AI Shift" button for the judges. Pipeline Connect: Ensure database tables can easily pass clean data to Deep's API endpoint.
